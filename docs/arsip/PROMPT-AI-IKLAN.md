# Prompt AI — Video Iklan & Poster Les Ko Lui

**Gunakan prompt ini untuk AI video generator (Runway, Pika, Kling) atau AI image editor (Canva AI, Adobe Firefly, Midjourney) untuk membuat konten Instagram dari screenshot aplikasi.**

---

## COPY PROMPT INI ↓

```
Kamu adalah creative director untuk campaign Instagram sebuah aplikasi edukasi bernama **Les Ko Lui** — sebuah PWA untuk tutor les privat IB & kurikulum internasional di Indonesia.

### TENTANG APLIKASI
Les Ko Lui adalah aplikasi all-in-one untuk tutor privat. Fitur utamanya:
- **Catat sesi les** — rekam mapel, topik, foto, mood, engagement siswa, prediksi nilai
- **Laporan bulanan otomatis** — PDF/JPEG laporan progres ke orang tua dengan layout template cantik (Cards, Timeline, Scrapbook, Dashboard, Portfolio, dll ~20 layout)
- **Kalender & jadwal** — atur jadwal les berulang (series), deteksi conflict, reminder
- **Manajemen PR** — beri PR, lacak status (selesai/belum/telat), notifikasi deadline
- **Rekap keuangan** — tagihan otomatis per bulan, status bayar, export PDF invoice
- **Tanda tangan digital** — murid tanda tangan di layar, tersimpan di sesi
- **Absensi export** — PDF absensi dengan tabel durasi, materi, TTD, dan info transfer bank
- **AI (DeepSeek)** — generate narasi laporan, analisis pola siswa, saran PR, polish chat WA ke ortu
- **Backup terenkripsi** — AES-GCM, restore dengan password, auto-backup mingguan
- **Offline-first PWA** — semua data tersimpan di device, bisa dipakai tanpa internet
- **IB-ready** — kurikulum IB MYP, IB DP, Cambridge IGCSE/O Level/AS/A Level, AP, Nasional, Custom

### TARGET AUDIENCE
Tutor privat, guru les, pemilik bimbingan belajar di Indonesia. Umur 20-40. Aktif di Instagram. Ingin tools profesional tapi simpel. Bangga dengan kualitas mengajar mereka.

### BRAND VOICE
- Profesional tapi hangat — bukan korporat kaku
- Bangga ("gue punya app keren nih") — bukan jualan agresif
- Clean, modern, colorful — sesuai tema UI app (biru, pastel, rounded)
- Bahasa Indonesia santun tapi casual (pakai "kamu", bukan "Anda")

### YANG SAYA PUNYA
Folder screenshot aplikasi (14 gambar, resolusi tinggi) — isinya:
1. Dashboard home + kalender
2. Calendar day detail
3. Daftar murid dengan statistik
4. Detail murid + riwayat sesi
5. Form rekam sesi les
6. Halaman tugas/PR
7. Laporan bulanan dengan template
8. Rekap keuangan + tagihan
9-11. Settings (profil, AI, PIN, bank, backup)
12. Modal update "What's New"

### YANG SAYA MINTA — BIKIN 3 HAL:

---

**A. VIDEO IKLAN 30 DETIK (Instagram Reels / TikTok)**
- Format: 9:16 vertical, 1080×1920
- Style: clean product demo tanpa VO — pakai text overlay saja
- Alur:
  0-3s   → Hook: text "Guru les tapi masih catat di buku tulis?" + footage app scrolling
  3-7s   → Demo cepat: tap kalender → rekam sesi → foto + TTD → simpan
  7-12s  → Showcase laporan: pilih template → preview PDF cantik → "Laporan ke ortu dalam 1 tap"
  12-18s → Fitur highlight: AI narasi, PR tracker, tagihan otomatis, backup aman
  18-25s → Montage 4 screenshot ditata dalam grid 2×2, zoom out
  25-30s → CTA: text "Les Ko Lui — Gratis, offline, aman" + link di bio
- Musik: lo-fi chill, upbeat tapi santai (no vocal)
- Transisi: smooth slide/fade, nggak perlu dramatis
- Warna dominan: biru (#3B82F6), putih, sentuhan gradien ungu
- Text overlay font: bold sans-serif (Inter/Poppins), putih dengan subtle drop shadow

---

**B. CAROUSEL INSTAGRAM (6-8 slide)**
- Format: 1:1 square, 1080×1080
- Slide 1 (Cover): Logo + "Les Ko Lui — App Untuk Tutor Profesional" + mockup HP menampilkan dashboard
- Slide 2: "Catat Sesi dalam 30 Detik" — screenshot form rekam sesi + bullet 3 benefit
- Slide 3: "Laporan Cantik ke Orang Tua" — 2 template laporan side-by-side
- Slide 4: "Atur Jadwal & PR" — screenshot kalender + tugas
- Slide 5: "Keuangan Rapi" — screenshot rekap + invoice
- Slide 6: "AI Bantu Kamu" — visual AI narasi + chat WA
- Slide 7: "Data Aman, Bisa Offline" — ikon backup + offline badge
- Slide 8 (CTA): "Coba gratis di leskolui.vercel.app" + QR code (bisa digenerate sendiri)
- Style tiap slide: background gradien subtle (biru→ungu, biru→teal, dll), screenshot app diletakkan di tengah dengan mockup HP atau shadow card

---

**C. POSTER / FEED POST (1 slide showcase)**
- Format: 1:1 square, 1080×1080
- Konsep: "Semua yang kamu butuhkan, dalam 1 app"
- Layout: 1 screenshot besar di tengah (home dashboard) + 6 screenshot kecil mengelilingi (masing-masing dengan label: "Catat Sesi", "Laporan", "Jadwal", "PR", "Keuangan", "Backup")
- Background: putih bersih dengan subtle grid pattern
- Header text: "Les Ko Lui" dengan font display + tagline kecil "App tutor privat Indonesia"
- Footer: link + "Gratis · Offline · Terenkripsi"
- Bisa juga variasi: mockup HP di tangan, dengan layout laporan yang keluar dari layar (3D effect)

---

### CATATAN TEKNIS
- Semua screenshot saya sudah dalam resolusi tinggi (retina @2x) — bisa di-scale down atau crop sesuai kebutuhan
- Kalau AI butuh spesifik screenshot mana, pilih yang paling visually rich: dashboard (01), detail murid (04), laporan (07), settings bank (11)
- Jangan pakai foto orang — enough dengan UI screenshots saja
- Kalau bikin video, teks jangan terlalu banyak — 3-5 kata per scene cukup
- Hashtag saran: #LesKoLui #TutorPrivat #IBTutor #AplikasiPendidikan #TutorIndonesia #EdTech #GuruKeren #BelajarOnline
```
